01

文生圖 Text-to-Image

ComfyUI 最基礎的 workflow，輸入文字描述產出全新圖像。下方附加節點（LoRA、ControlNet）可按需插入主流程，無需改動基礎骨架。

  • Checkpoint Loader 載入 SD / SDXL 模型，輸出三條線：model、CLIP、VAE
  • CLIP Text Encode × 2 分別輸入正向與負向 Prompt；Empty Latent Image 設定輸出尺寸
  • KSampler 接收模型、正負 Prompt、Latent，設定 steps（20～30）、cfg（7）、sampler 後去噪
  • VAE Decode → Save Image 將 Latent 解碼為像素圖並存檔
＋ LoRA Loader（附加節點）
  • 插在 Checkpoint 後，串接 model 與 CLIP 兩條線，不破壞後續節點
  • 可疊加多個 LoRA（串接），各自設 strength（0.6～0.9），總強度建議 ≤ 1.5
  • 常見 LoRA 類型：畫風（水彩、像素）、角色（特定 IP）、動作姿勢、光線技法
  • 部分 LoRA 需在 Prompt 加入 觸發詞（trigger word） 才能啟用
＋ ControlNet（附加節點）
  • ControlNet Loader 載入對應模型；Load Image 提供控制條件圖
  • Apply ControlNet 節點將條件注入 positive conditioning，再送進 KSampler
  • 常用模型：Canny（線稿邊緣）、Depth（深度圖）、OpenPose（人體骨架）、Lineart（線稿上色）、Tile（細節補強）
  • strength 調控影響程度：0.8～1.0 強制跟隨控制圖，0.4～0.6 保留生成自由度
入門必學SD 1.5 / SDXLLoRA 串接ControlNetOpenPoseCanny / Depth
02

圖生圖 Image-to-Image

以現有圖像為起點，透過 VAE Encode 進入 Latent 空間，KSampler 按 Prompt 引導重繪。搭配 LoRA 強化風格一致性，搭配 ControlNet 鎖定構圖與姿勢。

  • Load Image → VAE Encode 將參考圖壓縮進 Latent 空間，保留結構與色彩資訊作為去噪起點
  • KSampler 的 denoise 值是核心參數：0.3 幾乎不改動，0.9 接近完全重繪
  • 常見應用：換風格（真實→動漫）、換季節、換光線、線稿上色
＋ LoRA Loader（附加節點）
  • 插在 Checkpoint 與 KSampler 之間；圖生圖的 strength 建議略低（0.5～0.7），避免 LoRA 風格壓過原圖結構
  • 典型用途：讓重繪結果套上特定動漫畫風 LoRA，在保留原圖構圖的同時轉換風格
  • 可堆疊多個 LoRA：先掛畫風 LoRA（線條感），再掛色調 LoRA（暖色/冷色），精準控制目標風格
＋ ControlNet（附加節點）
  • Preprocessor 先行處理參考圖，提取邊緣、深度或骨架等控制圖，再送入 ControlNet Apply
  • 圖生圖常用搭配：Canny 保留線條結構（denoise 可拉高到 0.8）、Depth 鎖定空間透視關係
  • DWPose / OpenPose：即使換了服裝風格，人物姿勢依然與原圖一致
  • 雙重控制策略：ControlNet strength 0.8 鎖構圖 + denoise 0.65 允許色彩與風格自由發揮
denoise 調控風格轉換LoRA 風格強化PreprocessorCanny / DepthDWPose
03

多圖混合生圖 Composite

指定背景圖保留空間結構，前景圖注入角色或風格，兩路條件同時作用於 KSampler，輸出合成結果。

  • ControlNet Apply（接背景圖）以 Depth/Canny 模式鎖定空間構圖
  • IP-Adapter Apply（接前景圖）將主體的外觀或風格注入生成過程
  • 兩路條件各有 strength 權重，可調整背景構圖與前景風格誰佔主導
  • 加入 Mask 節點可做精確的局部合成：只讓前景圖影響遮罩範圍
ControlNetIP-Adapter背景鎖定Mask 合成
04

單張靜畫 → 動畫 Img2Video

使用 Stable Video Diffusion（SVD）或 AnimateDiff，從單一靜態圖出發，生成連續多幀動畫。

  • SVD 路線：SVD Image Encoder 提取起始圖語義 → VideoSampler 生成多幀 Latent → VAE 批次解碼 → 合併輸出
  • AnimateDiff 路線：在文生圖 workflow 中插入 AnimateDiff Loader，KSampler 直接輸出多幀
  • motion_bucket_id 控制運動幅度（127=中等），值越大動得越劇烈
  • 建議輸出 16～25 幀（約 1～2 秒），幀數過多容易出現 temporal artifacts
SVDAnimateDiffmotion_bucketVHS 節點
05

多張靜畫 → 動畫 Keyframe Animation

載入多張關鍵幀，以 Image Batch 組合為序列，AnimateDiff 負責關鍵幀間的動態補間。

  • Image Batch 節點將所有幀依順序組合成 batch，維度為 [N, H, W, C]
  • AnimateDiff Loader 載入運動模型（mm_sd_v15 等），搭配 Motion LoRA 控制運動類型
  • video_length 設為目標幀數（如 24 幀 = 1 秒 @ 24fps），超出關鍵幀的部分由模型補間
  • 適合製作 循環動畫、角色動作序列，比 SVD 更可控
Image BatchAnimateDiffMotion LoRA關鍵幀補間
06

Inpainting 局部重繪

用遮罩精確指定要修改的區域，模型只對白色遮罩範圍去噪生成，其餘像素完全保持不動。

  • Load Mask 可直接繪製或從圖像提取：白色=要重繪，黑色=保留
  • VAE Encode 需切換 Inpaint 模式，否則遮罩資訊無法正確傳入 Latent
  • 遮罩區的 KSampler 設 denoise=1.0，讓模型完全自由地生成新內容
  • 常見應用：換臉、換背景、消除物件、替換服裝、修補瑕疵
  • 進階：搭配 FaceDetailer 自動偵測臉部區域做局部重繪
局部修改Mask換背景消除物件
07

Hires Fix 高解析放大

先以低解析度生成構圖草稿，放大後二次去噪補強細節，避免直接大圖生成的結構崩潰問題。

  • 直接生成 2048px 大圖容易出現重複結構、臉部扭曲等問題，分兩階段可有效避免
  • 推薦放大模型：4x-UltraSharp、RealESRGAN x4plus（照片），4x_AnimeSharp（動漫）
  • 第二次 KSampler 的 denoise 約 0.3～0.45，太高會破壞構圖，太低細節不夠銳利
  • 也可用 Tiled KSampler 分塊處理超大圖（4K+），節省 VRAM
2x / 4x 放大Upscale 模型Tiled 分塊細節補強
08

LoRA 風格微調

在 Checkpoint 基礎上插入一到多個 LoRA，精確注入特定風格、角色或技法，不需重新訓練主模型。

  • LoRA 串接不限數量，但總 strength 建議 ≤ 1.5，避免多個 LoRA 互相干擾造成畫面崩潰
  • 部分 LoRA 有觸發詞（trigger word），必須加進 Prompt 才能啟用，查看 LoRA 說明頁
  • 常見類型：畫風 LoRA（水彩、油畫、像素）、角色 LoRA（特定 IP）、動作 LoRA（構圖、光線）
  • 搭配 LoRA Stacker 節點可一次管理多個 LoRA 的 strength，更方便
LoRA Loader串接疊加觸發詞風格注入
09

SDXL + Refiner 兩階段生成

SDXL 官方推薦雙模型流程：Base 負責前 75% 去噪建立構圖，Refiner 接手後 25% 強化細節，品質顯著優於單模型。

  • 兩個 KSampler 共用同一個 Latent 張量，不需 VAE 中間解碼，速度快
  • Base：steps=20、end_at_step=15；Refiner：start_at_step=15、steps=20（共享 step 計數）
  • Refiner 有專屬 CLIP Encode，Prompt 可以與 Base 不同，用來補強細節描述
  • 僅限 SDXL 系列（含 Juggernaut XL 等衍生模型），SD 1.5 無此機制
SDXL 專屬end_at_step兩階段推理細節精修
10

Prompt 插值 / 圖像變體

固定同一 seed，只改變 Prompt 或 CFG，批次生成多個版本對比，精準觀察每個詞語的影響力。

  • 固定 seed 讓初始噪聲相同，差異完全來自 Prompt 或參數變化，控制變數更精準
  • 可用 Batch Count 或 XY Plot 節點一次跑多組（如 CFG 從 5 到 12 每步 1）
  • XY Plot：X 軸控制一個變數（CFG），Y 軸控制另一個（steps），輸出格狀比較圖
  • 常用來確認最佳 cfg、steps 組合，或比較不同 Sampler 的風格差異
固定 SeedXY Plot批次對比參數調優
11

臉部修復 FaceDetailer / ADetailer

以 YOLO 自動偵測圖中所有臉部，裁切為高解析局部圖後重繪，再精準貼回原圖位置。

  • FaceDetailer（來自 ComfyUI-Impact-Pack）包含偵測→裁切→重繪→貼回完整流程
  • 裁切後的局部圖通常在 512～768px 推理，解析度夠高才能生出清晰臉部
  • Prompt 可以是 「detailed face, sharp eyes, natural skin」，針對臉部細節描述
  • 可設定 bbox_threshold（偵測閾值）避免誤偵測非人臉物件
  • 通常置於主 workflow 最後，幾乎是人像生成的標準後處理
YOLO 偵測局部重繪Paste Back人像必備
12

Flux / DiT 現代架構

Flux.1、SD3 等新世代 DiT 架構模型，採用雙文字編碼器與全新 Sampler，節點結構與傳統 SD 截然不同。

  • CLIP-L + T5-XXL 雙編碼器：短 Prompt 用 CLIP-L 抓風格，長細節描述交給 T5-XXL（理解能力遠優於 CLIP）
  • 無負向 Prompt：Flux 以 guidance 參數（≈ 3.5）取代 CFG，不支援也不需要負向詞
  • Flux-schnell：僅需 4 步即可生成高品質圖，速度極快但適合輕量應用
  • Flux-dev：steps 約 20～30，品質更高，文字生成、複雜構圖、手部描繪都顯著優於 SD
  • VAE 使用 Flux 專用的 AE（Autoencoder），不能混用 SD 的 VAE
