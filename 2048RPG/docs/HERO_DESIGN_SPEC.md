## 壹、核心設計哲學與矛盾消除總則 (Core Principles)

本規範經過實機棋盤小尺寸（64px/40px）測試與使用者反饋，已徹底消除早期提案中的矛盾，確立以下不可動搖的最高準則：

1. **嚴格 2.0 ~ 2.2 頭身大頭短身 (Strict 2.0 Head-to-Body Ratio)**
   * **為何必須 2.0 頭身**：在手遊 5x5 棋盤中，方塊實際像素僅約 48px~64px。只有大頭短身（頭部高度佔全身 45%~50%），才能在縮小後依然看清精緻面容與五官！
   * **正方形填充**：2 頭身量體自然趨近正方形（寬高比接近 1:1），左右手持握劍盾自然微張即可佔滿 256x256 畫布（Bounding Box 覆蓋率 > 85%），徹底消除「3頭身人物過於瘦長、在方塊中縮成小黑點、兩側大量留白」的致命缺點。

2. **美術風格完全錨定【數值 512 測試之風格 2：3D 桌遊黏土雕塑】(Clay Figurine)**
   * 溫潤飽滿的實體黏土（Polymer Clay）手作質感、粗厚塊面（Chunky Shapes）、大幾何邊緣。
   * 採用高對比、明亮高飽和色調（PhotoCraft 基準校色：亮度 $+22\%$、對比 $+28\%$、飽和 $+25\%$），告別灰暗啞光。

3. **100% 清晰露臉，告別鐵罐人 (100% Visible Open Faces)**
   * **全員露臉**：無論階級高低，一律展現生動大眼、自信英挺五官與飛揚髮型。
   * **頭盔定位**：頭盔僅作為「額甲、側翼、冠冕、羽飾」的裝飾點綴，**嚴禁任何把臉部完全封死的十字桶盔、封閉面罩或無臉頭盔**！

4. **動作定位為【人物舉著武器的備戰待機動作 (Idle Ready Stances)】**
   * **嚴禁攻擊揮砍瞬間**：揮刀殘影（Slash Trails）、大跳劈或前撲撲倒，皆為攻擊瞬間動畫，**無法作為常態待機使用**。
   * **待機姿態定義**：雙腳穩立地面、雙手持握/舉起武器、盾牌護身，保持專注備戰狀態。4 個階級透過「握劍手勢、劍扛肩、橫劍胸前、高舉待命、盾牌架劍」等不同**待機架式**產生鮮明剪影差異，完美對接後續 2~5 幀的呼吸跳動微動畫（Idle Breathing Loop）。

5. **裝備吸收因果 1:1 強烈連動 (Equipment Resonance)**
   * 角色手上握持的劍、盾與胸甲，必須嚴格復刻 16 階實體黏土裝備圖鑑（Style E），讓玩家一眼看出「剛才吃進了哪件神兵，現在正穿在身上」！

6. **螢光洋紅幕 (Hot Magenta #FF00FF) Chroma Key 智慧去背**
   * 消除手臂內彎、雙腿跨下、劍盾與身體夾縫中所有的**封閉環形色塊（Enclosed Holes）**。
   * 絕對保護眼白、皮膚、純白鎧甲與高光金屬，零誤傷、零空洞。

## 肆、技術管線與去背標準 (Chroma Key & Output Specs)

### 1. 螢光洋紅幕規格
* 提示詞強制指定：`Solid flat uniform pure vibrant magenta screen (#FF00FF), completely isolated, no floor cast shadows, no pedestals`。
* **背景色相判定公式**：
  $$\text{min}(R, B) - G > 30 \quad (\text{洋紅幕條件})$$
  凡符合條件者，Alpha 通道一律剔除為 0。手臂與身體夾縫、雙腿跨下之**封閉環狀孔洞（Holes）自動 100% 鏤空**。

### 2. 邊緣溢色抑制 (Despill)
* 對於過渡邊緣像素，自動進行邊緣抑制：
  $$R_{\text{clean}} = \text{clamp}(R - \text{spill} \times 0.75, 0, 255)$$
  $$B_{\text{clean}} = \text{clamp}(B - \text{spill} \times 0.75, 0, 255)$$
  徹底消除角色邊緣的粉紅色毛邊。

### 3. 256x256 正方形畫布置中與填充
* 角色切片等比縮放：$\text{scale} = 244.0 / \max(\text{width}, \text{height})$。
* 居中貼入 $256 \times 256$ 純透明畫布，**Bounding Box 覆蓋率保持在 85% ~ 95%**，保證在棋盤方塊中飽滿巨大。
