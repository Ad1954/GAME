## 📌 1. 專案概述與核心架構

本作《2048 RPG：王國遠征》（Commercial Edition）為純直式（Portrait Mode，480px）商業化手遊，完全獨立於原型版本，專注於手機沉浸體驗、長線養成與輕度數值策略。

### 核心模組架構 (`Commercial_Edition/src/`)
- `core/`：
  - `Constants.js`：全域常數定義、關卡怪物池 (`CHAPTER_MONSTER_POOLS`)、數值升階定義、音效設定與素材路徑映射。
  - `GameState.js`：遊戲核心狀態管理、進度存檔與 `localStorage` 讀寫。
  - `CombatEngine.js`：單關卡獨立戰鬥引擎（同值翻倍融合、強弱斬殺判定、折半回落、裝備無害阻擋）。
- `presentation/`：
  - `HubPresenter.js`：四大分頁大廳管理（商店、裝備、冒險、公會）。
  - `CombatPresenter.js`：5x5 戰鬥盤面動態渲染、勇者位移、方塊生成預告與滿盤瀕危警示。
  - `AudioSystem.js`：Web Audio API 程式化合成音效與背景音樂。
  - `GwtRunner.js`：前端即時 GWT 規格驗收套件。

### 第 VIII 章敵對重構重大設計決策
- **問題**：第 VIII 章原神明外觀為純白色光翼與金冠，於 5x5 棋盤與玩家白色勇者方塊視覺混淆，敵我難辨。
- **解決方案**：全面重構為「黑曜玄甲 ＋ 猩紅天罰光冕 ＋ 暗金神紋」，65536 換裝黑羽墮翼、131072 化為懸浮黑曜十二面體與紅光眼眸、262144 塑造為日蝕血月六翼終局神皇，達成極致陣營反差。

### 去背標準管線 (M-REQ-08 Chroma Key Standard)
- 針對不同魔物本體色相，採用反差互補色（桃紅 `#FF00FF` 或純綠 `#00FF00`）。
- 使用 HSV 色相分離、邊緣羽化抗鋸齒、RGB 連通邊界孔洞穿透算法，並消除邊緣色溢（Despill），達成 100% 乾淨透明。
