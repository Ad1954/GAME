# 《2048 RPG：王國遠征》商業版 UI/UX 視覺重構與自適應設計規格書 (v6.0)

> **版本**：`v6.0 Commercial Edition UI/UX Master Spec`  
> **制定日期**：2026-10-28  
> **核心目標**：參照《皇室戰爭》(Clash Royale) 飽滿清晰的手遊視覺標準，全面解決字體偏小、層次過深與自適應飄移問題。

---

## 📌 一、 核心設計原則與防呆紅線 (Core Design Principles)

### 1. 「3 層以內可接觸」極致扁平化 (Depth $\le$ 3)
* 玩家從任何畫面出發，最多只需 **1~2 次點擊** 即可直接觸達目標機能（如抽卡、合成裝備、升級科技、切換英雄）。
* 嚴格禁止超過 3 層的抽屜式或多重 Modal 巢狀嵌套。

### 2. 「告別小字」手遊級字體層級規範 (Typography System)
不再使用網頁端偏小的 10~12px 字體，全面升級為飽滿粗體手機規格：

| 層級名稱 | 尺寸 (rem / px) | 字重 (Font-Weight) | 適用場景 |
| :--- | :--- | :--- | :--- |
| **超大標題 (Hero Heading)** | `1.65rem ~ 1.85rem` (26~30px) | 900 (Black / Extra Bold) | 關卡名稱、大獎獲得、勝利大標 |
| **卡片主標 (Card Title)** | `1.25rem ~ 1.40rem` (20~22px) | 800 (Bold) | 分頁大標、功能模組標題、英雄名稱 |
| **主要內文與按鈕 (Body & CTA)** | `1.05rem ~ 1.15rem` (17~18px) | 700~800 (Bold) | **所有點擊按鈕**、核心數值、主要說明（按鈕絕不小於 16px） |
| **次要輔助標籤 (Caption / Sub)** | `0.88rem ~ 0.95rem` (14~15px) | 600 (Semi-Bold) | 體力倒數、建議數值、道具說明（**絕對禁止 < 13px 極小字**） |

### 3. 全端自適應與安全邊界防護 (Safe Area & Responsive System)
徹底杜絕「實測才發現切邊」的痛點，定義標準容器與邊界：

* **頂部安全區 (Top Inset)**：`max(12px, env(safe-area-inset-top))`，完整避讓 iPhone 動態島 (Dynamic Island) 與前置鏡頭。
* **底部安全區 (Bottom Inset)**：`max(8px, env(safe-area-inset-bottom))`，完整避讓 iOS 底部小白條 (Home Indicator)。
* **兩側防貼邊邊距 (Side Padding)**：固定 `16px`（平板端自動放大至 `24px`），卡片永遠不緊貼螢幕邊框。
* **多端自適應響應標準 (Breakpoints)**：
  * **手機端 (Mobile Phone, 360~480px)**：以標準 `480px` 為最大寬度，高度自適應，元件採百分比彈性縮放。
  * **平板端 (iPad / Tablet, 600~820px)**：主容器放寬至 `600px`，間距等比拉大，棋盤維持置中，按鈕維持舒適點擊面積。
  * **電腦桌面端 (Desktop PC)**：置中 480px 模擬框，外加高階暗色陰影隔離。

## 🏛️ 二、 五大底欄導覽列架構 (Bottom 5-Tabs Navigation)

為徹底解決「操作層數過深」的疑慮，確定採用 **5 大獨立底欄按鈕**，將【軍備整備】與【英雄養成】獨立拆分，達成 **「1 點擊即刻抵達」**：

```
┌──────────────────────────────────────────────────────────────┐
│ [ 🛒 商店 ]  [ 🎒 軍備 ]  [ ⚔️ 冒險 ]  [ 👑 英雄 ]  [ 📜 圖鑑 ] │
└──────────────────────────────────────────────────────────────┘
```

1. **【🛒 商店 (Shop)】**：5 大精品化商品（免廣告特權、每日 1000G 補給、30元道具包、30天無限體力、5萬金幣包）。
2. **【🎒 軍備 (Armory)】**：出戰裝備槽、48 階軍備科技升級卡、裝備背包網格（一鍵合成 ＋ 轉蛋抽裝備）。
3. **【⚔️ 冒險 (Adventure)】**：**皇室戰爭式主首頁**（中央單一最新關卡卡片 ＋ 左右懸浮活動膠囊 ＋ 巨大出擊按鈕）。
4. **【👑 英雄 (Heroes)】**：三大經典職業立繪卡片（戰士、弓箭手、商人），即時切換出戰、金幣升級技能冷卻。
5. **【📜 圖鑑 (Archive)】**：魔物圖鑑（40 階黏土微縮公仔） ＋ 神兵圖鑑 ＋ 通關成就與版本歷程。

## 🛡️ 四、 AI 第一波自動化自適應與樣式把關檢驗流程 (Pre-flight QA SOP)

為杜絕「每次都要實測才發現切邊或字太小」，建立本專案專屬的 **AI 自動化前端品質把關清單**：

1. **字級硬性門檻檢核 (Min-Font Size Assertion)**：
   * 所有按鈕字體 `font-size >= 16px` (1.0rem)。
   * 所有說明與次要標籤 `font-size >= 14px` (0.88rem)。
   * 嚴格禁止全站出現低於 `13px` 的任何文字。
2. **Safe Area 容器全覆蓋檢核**：
   * 頂部與底部必須宣告 `env(safe-area-inset-top)` 與 `env(safe-area-inset-bottom)`。
   * 嚴格禁止按鈕或資訊貼死在最上端 0px 或最底端 0px。
3. **按鈕最小觸控熱區 (Touch Target Size)**：
   * 任何可點擊元素（包含關卡箭頭、關閉按鈕）高與寬不得低於 `44px x 44px`，保證手機單手好按不誤觸。
4. **平板與桌面防變形檢核 (Tablet & Desktop Max Bounds)**：
   * 容器設置 `max-width: 480px`（平板模式下寬度拉伸不超過 `600px`），確保在 iPad Pro 上棋盤與按鈕比例協調，不橫向被拉扁。
5. **文字防溢出安全保護**：
   * 關卡名稱與描述一律設定 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`，防止在 360px 小型手機上撐爆換行破圖。
