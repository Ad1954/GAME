## 壹、核心設計哲學：小尺寸可讀性第一 (Legibility & Simplicity First)

在 2048 棋盤的微縮尺寸（約 48px ~ 64px）下，**細節越多，縮小後越糊成一團雜訊**。  
魔物設計追求的絕非「複雜精細」，而是**「極致簡潔、大塊面、強特徵、高辨識」**！

### 核心要素約束總表 (Master Checklist)

每次進行魔物美術生成與切片時，必須逐條對照本表，違規者一律不予通過：

| 編號 | 核心要素 (Element) | 嚴格指標與規範 (Mandatory Rules) | 絕對禁止之反例 (Forbidden) |
| :---: | :--- | :--- | :--- |
| **M-REQ-01** | **極致簡潔大塊面<br>(Chunky Clay Forms)** | **手作黏土大塊面**。幾何輪廓圓潤飽滿，表面乾淨利落，像極簡桌遊黏土棋子。 | ❌ **嚴禁細碎刻線、細密毛髮紋理、微雕金屬飾品**（縮小必成噪點）。 |
| **M-REQ-02** | **招牌特徵誇張放大<br>(Exaggerated Features)** | **抓取 1~2 個核心特徵誇張放大**，確保縮至 48px 時一眼可辨（例：蝙蝠大耳、狼尖耳、哥布林招牌長耳、史萊姆水滴身、獸人寬下巴與粗白獠牙）。 | ❌ **嚴禁全身佈滿均勻碎節**，導致視覺焦點渙散。 |
| **M-REQ-03** | **強烈剪影辨識度<br>(Bold Silhouette)** | **剪影優先**。即使將圖片轉為純黑剪影，依然能在 0.1 秒內憑外型輪廓辨識魔物種類。 | ❌ **嚴禁輪廓軟趴趴或縮成球狀一團**，喪失輪廓辨識度。 |
| **M-REQ-04** | **高對比純淨色塊<br>(Color Blocking)** | **鮮明飽滿純色色塊**。色彩層次最多 2~3 個色階，邊緣對比鮮明。 | ❌ **嚴禁灰暗髒色、過度細膩的寫實漸層陰影**。 |
| **M-REQ-05** | **畫布佔比與量體<br>(Bounding Box)** | **物件佔比 80%~85% 居中**，形態飽滿，適配長方形 5:6 盤面與正方形方塊。 | ❌ **嚴禁過於細長或左右過度留白**。 |
| **M-REQ-06** | **背景去背品質<br>(Clean Background)** | **純色背景與精確 Alpha 去背**。輪廓邊緣平滑乾淨，無毛邊雜色。 | ❌ **嚴禁白邊殘留或外輪廓缺損**。 |
| **M-REQ-07** | **零死灰白陰影硬塊<br>(Zero Solid Shadows)** | **1. 徹底消除地面死灰白硬塊**：公仔腳底與接觸面的陰影，**嚴禁以不透明灰白像素（RGB 180~235）殘留**。<br>**2. 純粹本體裁切 ＋ CSS 動態立體投影**：公仔邊緣必須 100% 俐落乾淨，將陰影交由遊戲與展廳的 CSS `drop-shadow` 自動計算，確保在任何方塊底色上皆為完美動態投影。<br>**3. 若保留陰影必須為純黑 Alpha 半透明**：嚴禁任何灰白硬塊，陰影必須轉為純黑 `#000000` 搭配 $0\% \sim 35\%$ Alpha 平滑衰減。<br>**4. 量體保護**：Bounding Box 計算**僅以公仔本體實體為準**，絕不可將陰影納入，杜絕 Boss 被陰影拉大畫布而被迫縮小！ | ❌ **嚴禁腳底踩著一塊灰白/亮白死板硬塊**。<br>❌ **嚴禁因陰影色塊導致公仔實體比例縮水變小**。 |
| **M-REQ-08** | **特殊底色 Chroma Key 強制規範<br>(Chroma Key #FF00FF / Pure Green)** | **1. 嚴禁純白背景生成**：純白背景必然導致封閉孔洞（雙腿胯下、手臂腋下）無法穿透，且高彩度物體會產生漫反射染灰，破壞去背乾淨度。<br>**2. 特殊底色選用準則**：<br> - **冷色系/暗色系魔物（藍/灰/黑/紫）**：強制使用 `#FF00FF`（亮粉桃紅 / Pure Magenta）純色背景。<br> - **暖色系魔物（紅/橙/黃/火系）**：強制使用 `#00FF00`（純綠幕 / Pure Green）純色背景。<br>**3. 全圖孔洞 100% 穿透**：去背演算法必須全圖判定色度鍵，無論孔洞是否封閉皆 100% 去除背景，嚴禁孔洞殘留死白塊。<br>**4. 接觸面去背與邊緣 Despill**：對綠幕/桃紅反光進行色溢抑制（Despill），腳底與地面陰影徹底轉為乾淨透明。 | ❌ **嚴禁在純白或淺灰背景上生成魔物**。<br>❌ **嚴禁雙腿之間、手臂內側殘留封閉孔洞死白塊**。 |

## 拾壹、技術管線與去背標準 (Pipeline & Chroma Specs)

1. **圖片生成 (Image Generation)**：
   - **底色強制規範 (Strict Chroma Key)**：
     - **冷色/暗色系魔物（藍、灰、黑、紫、綠等非桃紅主體）**：Prompt 結尾強制加上 `isolated on pure solid vibrant magenta chroma key background (#FF00FF), high contrast separation, zero cast shadows, perfectly clean background for effortless transparent cutout`。
     - **暖色系魔物（紅、橙、黃、火系等與桃紅衝突主體）**：Prompt 結尾強制加上 `isolated on pure solid vibrant bright green chroma key background (#00FF00), high contrast separation, studio lighting, zero cast shadows, perfectly clean background for effortless transparent cutout`。
     - **❌ 絕對禁止在純白或淺灰背景上生成任何魔物圖片**。
   - 採用小兵 4 宮格大圖（2x2 格線），統一微縮模型燈光、俯視仰角與黏土材質。
   - 高階巨獸與 Boss 採用專屬提示詞，維持「簡潔大特徵、大色塊」。
2. **全圖孔洞穿透去背與裁切 (Python Script Processing)**：
   - **孔洞 100% 穿透 (Hole Penetration)**：嚴禁僅使用邊界 Floodfill。必須採用全圖色相/色度鍵（Chroma Keying）判斷（如桃紅 `#FF00FF`: `min(r, b) - g > 30`；純綠幕 `#00FF00`: HSV 色相 65°~125° 且 `g > max(r, b)`）。魔物雙腿胯下、手臂內側、翅膀孔隙皆能自動 100% 透空。
   - **色溢抑制 (Despill)**：針對邊緣漫反射綠光或桃紅光，自動將溢色通道抑制回黏土本體原色（如火靈下巴綠光收斂為橙黃黏土），杜絕綠邊或挖空瑕疵。
   - **零死灰白陰影 (Zero Solid Shadows)**：腳底接觸暗區若含背景反射色，一律歸入背景透明化；純本體裁切，動態陰影全交由遊戲 CSS `drop-shadow` 實現。
   - **量體保護與置中 (Bounding Box Centering)**：以去背後的本體實體為準計算 Bounding Box，以約 10~14px 邊界 Padding 均勻置中縮放至 256x256 RGBA PNG。
3. **儲存路徑**：
   - 存放於 `assets/images/monsters_clay/`。
   - 檔名規範：`monster_ch{章節編號}_{數值}.png`。
