# 2048 RPG：王國遠征 (Commercial Edition v1.2.8)
本目錄為 GitHub Pages 直接發布版。

## 部署與遊玩說明
1. 將本資料夾（或本資料夾內的所有檔案與資料夾）直接上傳至您的 GitHub 儲存庫根目錄。
2. 進入 GitHub 儲存庫 -> Settings -> Pages：
   - Source: Deploy from a branch
   - Branch: main (或 master)
   - Folder: / (root)
3. 儲存後稍候 1~2 分鐘，即可透過 https://<username>.github.io/<repo>/ 在手機或電腦直接暢玩！
