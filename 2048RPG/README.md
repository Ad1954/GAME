# 《2048 RPG：王國遠征》商業製品版 (Commercial Edition)

本目錄為獨立商業製品版（Phase 1），完全脫鉤於原型版本，專注於手機端體驗、長線養成與商業化發布。

---

## 📱 目標與架構設計

1. **純直式手遊佈局 (Portrait Mode)**：
   - 寬度鎖定最大 480px 居中適配，手機端全螢幕。
   - 採用類似《皇室戰爭 (Clash Royale)》的直覺 UI。
2. **頂部狀態與全域設定**：
   - 頂部常駐王國金幣顯示。
   - 右上角常駐【⚙️ 設定】圖標按鈕，支援音效切換與存檔重置。
3. **底部四大主題導覽列 (Bottom Nav)**：
   - 🛒 **商店**（Phase 3 開放小道具與軍備箱）
   - 🛡️ **裝備**（Phase 2 開放局外 2048 裝備融合與三部位裝備）
   - ⚔️ **冒險**（主頁：單線章節關卡挑戰）
   - 👥 **公會**（後續社群系統）
4. **單關卡獨立戰鬥引擎 (Single-Stage Combat)**：
   - 告別長程疲勞，單局 2~3 分鐘快速過關。
   - 5x5 棋盤，勇者出生於 (4, 0)。
   - 吸收裝備翻倍升級、強弱斬殺怪物、斬殺折半回落、裝備無害阻擋。
   - 全殲怪物勝利獲得賞金，解鎖下一關並存入 `localStorage`。

## 🚀 啟動方式

* **方式 1（一鍵啟動）**：
  雙擊本目錄下的 [`啟動製品版.bat`](file:///c:/Antigravity/2048RPG/Commercial_Edition/啟動製品版.bat)
* **方式 2（命令列啟動）**：
  ```bash
  cd c:\Antigravity\2048RPG\Commercial_Edition
  python server.py 8081
  ```
  打開瀏覽器訪問：`http://localhost:8081`
