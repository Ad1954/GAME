## 📱 核心特色與架構設計

1. **純直式手遊佈局 (Portrait Mode)**：
   - 寬度鎖定最大 480px 居中適配，手機端全螢幕沉浸體驗。
   - 採用類似《皇室戰爭 (Clash Royale)》的直覺 UI。
2. **頂部狀態與全域設定**：
   - 頂部常駐王國金幣顯示。
   - 右上角常駐【⚙️ 設定】圖標按鈕，支援音效切換與存檔重置。
3. **底部四大主題導覽列 (Bottom Nav)**：
   - 🛒 **商店**（小道具與軍備箱轉蛋）
   - 🛡️ **裝備**（局外 2048 裝備同值融合與三大裝備部位）
   - ⚔️ **冒險**（主頁：全 8 章節 240 關卡單線晉級挑戰）
   - 👥 **公會**（英雄殿堂與後續社群系統）
4. **單關卡獨立戰鬥引擎 (Single-Stage Combat)**：
   - 單局 2~3 分鐘快速過關，告別長程疲勞。
   - 5x5 棋盤，勇者出生於 (4, 0)。
   - 吸收裝備翻倍升級、強弱斬殺怪物、斬殺折半回落、裝備無害阻擋。
   - 全殲怪物勝利獲得賞金，解鎖下一關並存入 `localStorage`。
5. **微縮黏土美術生態池 (100% Complete)**：
   - 全 8 大章節（序章平原、綠野、迷霧森林、炙熱荒漠、冰封雪原、滅世黑曜、神魔深淵、終焉神域）共 40 隻魔物全數實裝微縮黏土風格圖資。
   - 嚴格遵守 `M-REQ-08` Chroma Key 去背規範，內嵌孔洞 100% 穿透無灰白死塊。
   - 第 VIII 章終焉神域採用「黑曜玄甲 ＋ 猩紅天罰光冕 ＋ 暗金神紋」，與玩家白色勇者形成極致陣營反差。
